# A股「质量 + 价值 + 成长」多因子策略复现

![Python](https://img.shields.io/badge/Python-3.11-blue) ![pandas](https://img.shields.io/badge/pandas-2.x-orange) ![License](https://img.shields.io/badge/License-MIT-green)

> 基于 AkShare 公开数据的 A 股多因子月度轮动策略。
> 完整实现 **Point-in-time 数据对齐 → 行业/市值中性化 → 滚动 ICIR 动态加权 → 行业集中度风控 → 宏观仓位管理 → 交易成本与无风险利率扣除 → 单因子 IC / 分组 / 分阶段稳定性检验** 的量化研究全流程。
> 11 年长周期回测（2014-01 ~ 2024-12，全量沪深300）：**年化收益 16.43%，超额夏普 0.79，最大回撤 -26.91%**。

## 🧠 策略逻辑

```
数据下载与本地缓存（多源容灾：新浪/腾讯/东财/百度/中证官网）
        ↓
构建因子面板（Point-in-time 时点对齐，防未来函数）
        ↓
横截面处理：去极值 → 行业/市值中性化(OLS残差) → 去极值 → 标准化 → 方向调整
        ↓
合成打分：滚动 12 个月 ICIR 动态加权（负 ICIR 自动归零）
        ↓
选出 Top 30（单行业 ≤ 6 只），等权构建目标组合
        ↓
宏观仓位管理（基准站上10月均线→满仓；跌破→半仓）
        ↓
按目标权重与实际持仓计算换手，扣除交易成本
        ↓
回测评估 + 单因子 Rank IC / 五分位分组 / 分阶段稳定性检验
```

### 因子体系

| 因子 | 类别 | 方向 | 中性化后方向调整 IC (11年) | 数据源 |
| :--- | :--- | :---: | :---: | :--- |
| ROE | 质量 | 正向 | **+0.016** (胜率58.8%) | 新浪财务指标（按披露日对齐） |
| PB | 价值 | 负向 | **+0.017** | 百度股市通历史估值 |
| 营收同比增速 | 成长 | 正向 | **+0.006** (胜率54.2%) | 新浪财务指标 |
| 资产负债率 | 风险 | 负向 | +0.003 | 新浪财务指标 |
| 过去6个月收益率 | 反转 | 负向 | +0.003 | 前复权日线 |
| 毛利率 | 质量 | 正向 | ≈ 0.000（纯噪音，被动态加权归零） | 新浪财务指标 |

## 🔬 研究洞察与分阶段稳定性检验

将 11 年回测期划分为三个阶段进行 IC 检验（`output/subperiod_ic.csv`），揭示 A 股风格演变与动态加权机制的核心价值：

| 中性化因子 | 2014-2017 | 2018-2021 | 2022-2024 | 稳定性结论 |
| :--- | :---: | :---: | :---: | :--- |
| **pb_n** | +0.046 | −0.034 | +0.047 | 典型 regime 翻转型：估值修复期强、抱团期失效 |
| **roe_n** | +0.023 | +0.033 | −0.017 | 核心资产时代王者，价值回归期失效 |
| **revenue_yoy_n** | +0.009 | +0.029 | −0.029 | 成长抱团期因子 |
| **mom_6m_n** | +0.012 | −0.023 | +0.026 | 熊市/震荡市的超跌反弹利器 |
| **debt_to_asset_n** | +0.009 | +0.005 | −0.005 | 长期弱正的防御型因子 |

1. **长周期下质量因子是核心 Alpha**：中性化后 ROE 全样本胜率 58.8%，“同行业内高盈利”是 A 股最长效的选股信号。
2. **低估值溢价在行业内长期有效**：PB 中性化后方向调整 IC +0.017，但呈现明显的周期翻转特征。
3. **毛利率的 Alpha 几乎全部来自行业暴露**：中性化后 IC 趋近于 0，11 年三个阶段均无效，属于纯噪音因子。
4. **短期反转是战术性机会**：6 个月反转因子在 6 年短周期 IC 高达 +0.04，长周期衰减至 +0.003，验证动量/反转的 regime 依赖性。
5. **中性化“救活”基本面因子**：短周期中 ROE 原始 IC 为负（“利好兑现”效应），剔除行业贝塔后翻正。
6. **动态加权实现风格自适应**：滚动 ICIR 机制在 2018-2021 自动重仓基本面因子、2022-2024 自动切换至价值与反转因子（最新一期权重：pb 64% / mom_6m 36%，基本面因子归零）。
7. **宏观风控“少亏”胜过“多赚”**：10 月均线仓位管理使历史平均仓位 76.52%，最大回撤由 -33.74% 降至 -26.91% 一线。

## 🛡️ 交易成本与实盘可行性

- **成本设定**：单边千分之三（含佣金、印花税、滑点），换入换出各计一次；仓位变动与行业约束产生的交易同样计费。
- **换手特性**：平均月度单边换手率 23.70%，年化成本约 1.71%；行业上限约束未显著推高换手。
- **超额口径**：夏普比率自最终版起扣除 2% 无风险利率，策略超额夏普 0.79 约为基准（0.16）的 5 倍。

## 🛠 技术栈与数据源

- **语言环境**：Python 3.11（推荐）
- **数据获取**：AkShare 多源容灾（行情：新浪→腾讯→东财；估值：百度股市通；成分股：中证官网；财务：新浪）
- **数据处理**：pandas 2.x / NumPy / SciPy（OLS 中性化、Spearman IC）
- **缓存机制**：本地 Parquet / CSV，二次运行秒开

## ⚠️ 局限性说明

1. **幸存者偏差**：使用当前沪深300成分股回测历史，未使用历史时点成分股；退市/剔除股未纳入；
2. **行业分类为当前 membership**：免费数据限制，未做到时点化行业归属；
3. **财务指标为单期报告值**：未做 TTM 处理；披露日采用保守固定滞后（绝对防未来函数，代价为少量信息延迟）；
4. **交易简化**：未处理涨跌停无法成交、停牌强制持有等细节（停牌价格 ffill 1 个月）；现金仓位收益按 0 计算；
5. **检验口径**：单因子 IC 与五分位分组图为毛收益口径，未扣除交易成本；
6. **数据源依赖公开接口**：可用性受上游网站策略影响。
