# A股 质量+价值+成长 多因子策略复现

本项目使用 Python 和 AkShare 公开数据，对 A 股质量、价值、成长多因子策略进行月度轮动回测。

## 📈 回测业绩 (2019-01 至 2024-12)
*股票池：沪深300成分股抽样 | 调仓频率：每月月末 | 选股数量：Top 30*

| 指标 | 多因子策略 | 沪深300基准 |
| :--- | :--- | :--- |
| **累计收益** | **203.98%** 🚀 | 22.90% |
| **年化收益** | **20.67%** | 3.55% |
| **夏普比率** | **0.91** | 0.27 |
| **最大回撤** | **-18.58%** 🛡️ | -39.92% |

## 🧠 因子逻辑
1. **价值因子**：PB (市净率，负向)
2. **质量因子**：ROE (正向)、毛利率 (正向)、资产负债率 (负向)
3. **成长因子**：营收同比增速 (正向)
4. **动量/反转**：过去6个月收益率 (负向，短期反转)

## 🛠️ 技术栈与数据源
- **语言/环境**：Python 3.11
- **数据获取**：AkShare (多数据源容灾机制)
- **数据处理**：Pandas 2.x, NumPy
- **缓存机制**：本地 Parquet 极速缓存

## 🚀 如何运行

1. 克隆仓库并进入目录：
   ```bash
   git clone <你的仓库地址>
   cd a-share-multi-factor

2. 创建虚拟环境并安装依赖（推荐 Python 3.11）：
   python -m venv .venv
   # Windows: .venv\Scripts\Activate.ps1
   # Mac/Linux: source .venv/bin/activate
   pip install -r requirements.txt

3. 运行回测：
   python main.py

4. 查看结果：
运行结束后，output/ 目录下会生成：
nav.png：策略与基准的净值曲线图
metrics.json：详细绩效指标
factor_panel.csv：因子面板数据
holdings.csv：历史每月持仓明细
